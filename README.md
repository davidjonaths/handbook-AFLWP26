# AIESEC Impact Quiz

A responsive 20-question quiz built with React and Vite, inspired by AIESEC's bright, global energy.

## Run locally

Install Node.js 18+ first, then:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Push this folder to a GitHub repository, import it into Vercel, and keep the default Vite settings. Every push to the connected branch will automatically trigger a new deployment.
